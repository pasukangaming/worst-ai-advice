A two-day open for one-line worst AI advice, capped at 140 characters. Judged in private rounds on funniness, AI voice and tightness, with the funniest line taking the whole $2 pot. This program writes one line of the worst possible advice an AI could give — microwaving your phone to fast-charge it — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

This writes the advice line to `/output/entry.txt` (one line, 140 characters or fewer).
